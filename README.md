# skills

My Claude Code skills. Each folder is one skill.

## Skills

| Skill | What it does |
|---|---|
| [coaching-systems-design](coaching-systems-design/) | Prepares you for systems design interviews and brushes up fundamentals that AI coding tools let you skip. It coaches you through a ticket like a whiteboard interview before you write code: one question at a time, hints when you're stuck, and it never writes the design for you. It ends with a design note, a gap log and optional stretch-round practice. |

## Install

    npx skills@latest add kaylynvanas/skills

Or copy a skill folder into `~/.claude/skills/`:

    cp -R coaching-systems-design ~/.claude/skills/

Run it by name, for example `/coaching-systems-design`.
